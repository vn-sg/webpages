简洁、响应式的中文研究网页，采用自包含 HTML、CSS 与 SVG，无构建步骤或第三方资源依赖。

## 当前版本

公开资料核验版，核验日期：2026-10-28。财务快照为 Q2 2026，并非实时行情或完整估值研究。

关联 ChatGPT 对话接口未返回原简报正文。因此，亲测报价、地区 TAM 数字及内部人交易记录未被复现；网页明确说明相关证据缺失。

## 查看与部署

直接用浏览器打开 `index.html`。静态托管时，将本目录设为发布目录；可上传至 Netlify，或连接本 GitHub 仓库部署。
